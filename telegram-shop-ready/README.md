# Telegram Shop Mini App

Готовый MVP магазина внутри Telegram.

## Что уже есть

- Telegram-бот с кнопкой открытия Mini App
- каталог товаров
- категории
- карточки товаров
- корзина
- оформление заказа
- проверка Telegram `initData` на сервере
- SQLite
- уведомление администратора о новом заказе
- адаптация под тему Telegram
- запуск одной Node.js-командой

## 1. Установка

Нужен Node.js 20+.

```bash
npm install
```

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните:

```env
BOT_TOKEN=токен_бота
WEBAPP_URL=https://ваш-домен.example
PORT=3000
ADMIN_CHAT_ID=ваш_telegram_chat_id
```

## 2. Запуск

```bash
npm start
```

Локально сайт будет доступен на:

```text
http://localhost:3000
```

Telegram Mini App требует HTTPS, поэтому для реального запуска нужен публичный HTTPS-домен.

## 3. Создание бота

В Telegram откройте BotFather, создайте бота через `/newbot` и вставьте полученный токен в `.env`.

После этого запустите сервер. Напишите боту `/start`.

## 4. Публикация Mini App

Разместите этот Node.js проект на VPS/Render/Railway/Fly.io или другом сервере с HTTPS.

Например:

```text
https://shop.example.com
```

Укажите этот адрес как `WEBAPP_URL`.

Бот уже отправляет кнопку `web_app`, которая открывает приложение.

## 5. Товары

При первом запуске создаются три демонстрационных товара.

Товары находятся в SQLite-файле:

```text
shop.db
```

Для полноценного проекта следующим шагом стоит добавить админ-панель для управления товарами.

## 6. Важное про оплату

Сейчас MVP создаёт заказ, но не списывает деньги.

Для реального магазина можно добавить Telegram Payments или подходящий внешний платёжный сервис. Платёжную интеграцию нужно делать на сервере и подтверждать успешную оплату webhook/ответом платёжного провайдера, а не только данными клиента.
